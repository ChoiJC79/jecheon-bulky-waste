# 버전 보관함

현재 작업 원본은 `v1.0.0` 기준선입니다.

다음 기능 변경 전에는 현재 소스를 `versions/v1.0.0/`에 보관하고, 작업 원본의 `VERSION`을 다음 버전으로 올립니다. 이후에도 같은 방식으로 직전 버전의 실행 가능한 소스를 유지합니다.

## 버전 규칙

| 변경 유형 | 예시 | 기준 |
|---|---|---|
| 패치 | v1.0.1 | 문구, 스타일, 오류 수정 |
| 마이너 | v1.1.0 | 화면, 업무 기능, API 추가 |
| 메이저 | v2.0.0 | 운영 배포 구조 또는 데이터 연계 방식 변경 |
