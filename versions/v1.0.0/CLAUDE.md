# Claude Code 작업 인수인계

## 프로젝트 목적

제천시 대형폐기물 신고를 시민·접수 담당자·현장 수거 담당자·최종 담당자가 함께 처리하는 위치기반 관리 시스템으로 구현한다.

## 현재 구현

- `index.html`, `styles.css`, `app.js`에 시민 신고 화면 프로토타입이 있다.
- `server.mjs`는 SQLite 기반 로컬 개발 API를 제공한다. 신고 저장과 읽기 전용 데이터 검증 요약을 지원한다.
- 품목 분류·검색·규격·수량·예상수수료, 배출 주소, 현재 위치 확인, 카드·계좌이체·현금결제 선택을 제공한다.
- 품목과 수수료는 예시 데이터다. 실제 운영 전 제천시 확정 수수료표의 마스터 데이터로 교체해야 한다.

## Claude Code 담당 범위

1. 내부 접수 담당자 대시보드를 만든다.
2. 현장 수거 담당자 모바일 화면을 만든다.
3. 현장 담당자가 배정 건, 신고 위치, 현재 위치, 품목·사진·특이사항을 확인하고 수거완료·미수거·현장변경 요청을 처리하게 한다.
4. 최종 담당자의 읽기 전용 데이터 검증 화면을 만든다.

## 반드시 지킬 기준

- 외부 시민 서비스와 새올행정망 내부 시스템을 직접 DB 연결하지 않는다.
- 수거자의 상시 위치추적과 이동경로 저장을 구현하지 않는다.
- 현장 위치는 작업 건을 열거나 처리할 때만 사용한다.
- 최종 담당자에게 임의 SQL 실행 또는 DB 쓰기 권한을 제공하지 않는다.
- 카드번호나 계좌 비밀번호를 저장하지 않는다.

## 실행과 검증

```bash
npm run dev
npm test
```

현재 UI 테스트용 Playwright 패키지는 설치되어 있지 않다. 설치 후 `tests/ui-smoke.py`를 실행해 시민 신고 흐름을 검증한다.
