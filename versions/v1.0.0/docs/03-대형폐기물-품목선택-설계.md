# 대형폐기물 품목 선택 설계

## 설계 기준

제천시의 공개 안내는 냉장고·장롱·책상 등을 대형폐기물 신고 대상으로 예시하고 있다. 다만 실제 신고 품목과 수수료는 조례·수수료표의 최신 기준이 적용되어야 하므로, 서비스의 품목 목록과 금액은 관리자가 관리하는 공식 품목 마스터에서만 제공한다. [제천시 쓰레기종량제 안내](https://www.jecheon.go.kr/www/contents.do?key=497)

시민 화면에서는 행정용 품목 코드나 긴 목록을 먼저 보여주지 않는다. `대분류 → 세부 품목 → 규격·상태 → 수량` 순서로 좁혀 가며, 선택 결과에서 수수료와 배출 유의사항을 즉시 확인하게 한다.

## 시민 화면 배치

```text
[무엇을 버리시나요]
품목명 검색  예: 의자, 침대, 전자레인지

최근 선택      자주 찾는 품목
[의자] [침대]  [소파] [장롱] [책상] [매트리스]

분류별 선택
[거실·침실] [주방·식탁] [학습·사무] [침구·생활]
[주방·욕실] [유아·완구] [운동·레저] [가전제품] [기타]

선택한 분류의 세부 품목
소파  | 1인용 · 2인용 · 3인용 이상
침대  | 프레임 · 매트리스 · 세트
장롱  | 폭 또는 문짝 수 선택

선택 내역
소파 3인용 × 1        수수료 ○원
[품목 추가]                         [다음]
```

모바일에서는 한 화면에 대분류 카드 2열을 배치하고, 큰 아이콘과 한글 품목명을 함께 표시한다. 검색 결과와 분류 탐색 결과는 같은 상세 선택 화면으로 연결한다.

## 대분류와 세부 품목 예시

| 대분류 | 세부 품목 예시 | 규격 선택 예시 |
|---|---|---|
| 거실·침실 가구 | 소파, 장롱, 침대, 화장대, 서랍장, TV장 | 인원, 문짝 수, 가로폭, 분리 배출 여부 |
| 주방·식탁 가구 | 식탁, 식탁의자, 찬장, 싱크대 | 인원, 길이, 상·하부장 구분 |
| 학습·사무 가구 | 책상, 책장, 의자, 캐비닛, 파티션 | 가로폭, 높이, 재질 |
| 침구·생활용품 | 매트리스, 이불, 카펫, 옷걸이, 거울 | 크기, 장수, 재질 |
| 주방·욕실·위생 | 식기건조대, 욕조, 변기, 세면대 | 규격, 분리 여부 |
| 유아·완구 | 유아침대, 유모차, 놀이시설, 장난감 | 크기, 전동 여부 |
| 운동·레저 | 자전거, 러닝머신, 운동기구, 텐트 | 크기, 분해 여부 |
| 가전제품 | 냉장고, 세탁기, TV, 전자레인지, 에어컨 | 용량, 화면 크기, 실외기 포함 여부 |
| 기타 대형생활용품 | 액자, 피아노, 화분, 대형 플라스틱류 | 크기, 재질 |

위 예시는 화면 분류를 위한 것이며, 실제 노출 품목·규격·금액·배출 가능 여부는 제천시의 확정 수수료표로 검수한 뒤 등록한다.

## 선택을 쉽게 만드는 보조 기능

- 자동완성 검색은 동의어를 함께 지원한다. 예를 들어 `쇼파`를 입력해도 `소파`를 제시한다.
- 자주 신고되는 품목과 최근 선택 품목을 상단에 표시한다.
- 규격을 모르면 사진을 첨부하고 `규격 확인 요청`으로 접수할 수 있다. 이 경우 결제 전 담당자 검토 상태로 전환한다.
- 세트 품목은 프레임과 매트리스 등 구성품을 분리 또는 함께 선택하도록 안내한다.
- 전자제품은 무상수거 또는 별도 배출 대상 여부를 품목별로 안내하고, 해당하는 경우 일반 대형폐기물 결제를 막는다.
- 신고 대상이 아닌 건설폐기물·사업장폐기물·위험물은 별도 안내로 전환하여 잘못된 신고를 막는다.

## 관리자 품목 마스터

품목 마스터는 수수료 변경 때 화면과 결제 금액이 함께 바뀌도록 관리한다.

| 항목 | 내용 |
|---|---|
| 품목 코드 | 내부 업무용 고유 식별자 |
| 시민 표시명 | 검색과 화면에 노출할 명칭 |
| 대분류·세부분류 | 화면 탐색 구조 |
| 규격 선택지 | 인원, 가로폭, 용량, 문짝 수 등 |
| 수수료 | 규격별 신고 수수료 |
| 적용 기간 | 시행일과 종료일 |
| 배출 안내 | 분리 여부, 지정 배출장소, 유의사항 |
| 대체 경로 | 무상수거·재활용·건설폐기물 등 별도 안내 |
| 사용 여부 | 폐지 또는 일시 중지 품목 관리 |

수수료가 변경되어도 이미 결제완료된 신고의 결제금액은 변경하지 않으며, 변경 이후 새 신고부터 새 수수료를 적용한다.
