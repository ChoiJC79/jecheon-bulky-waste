# 망분리와 새올행정망 내부 업무 설계

## 구조

```text
시민 인터넷 웹
  │
  ├─ 신고·결제·조회 API
  │
인터넷 구간 서비스
  │
  └─ 보안 연계 중계 구간
        │
        └─ 내부 행정망 업무 API
              ├─ 접수 담당자 화면
              ├─ 수거 담당자 화면
              └─ 최종 담당자 데이터 검증 화면
                    │
                    └─ 내부 운영 DB와 읽기 전용 조회 DB
```

## 새올행정망 접속 방식

내부 담당자는 새올행정망에서만 접속 가능한 내부 URL로 업무 화면에 접근한다. 인증은 새올 단일인증 연계 가능 여부를 사전 확인하고, 연계가 어려우면 내부 전용 계정과 다중 권한 체계를 사용한다.

외부 시스템의 운영 DB를 내부망에서 직접 접속하거나, 내부 DB를 인터넷 서비스에 노출하지 않는다. 신고·결제·사진 등 외부 발생 자료는 보안성 검토를 거친 연계 규격으로 내부 업무 DB에 전달한다. 연계 실패 건은 자동 재시도와 별도 오류함으로 관리한다.

## 최종 담당자용 데이터 확인 화면

최종 담당자는 `데이터 검증` 메뉴에서 승인 전 데이터를 확인한다.

| 확인 항목 | 검증 내용 | 조치 |
|---|---|---|
| 접수 정합성 | 접수번호, 품목, 수수료, 배출일, 위치 좌표의 필수값 | 보완 요청 또는 오류 표시 |
| 결제 정합성 | 결제 완료 금액과 품목별 수수료 합계의 일치 | 결제 연계 오류함 이관 |
| 위치 정합성 | 제천시 행정구역 내 좌표 여부와 주소·좌표 불일치 | 위치 수정 요청 |
| 업무 정합성 | 배정 없는 수거예정 건, 완료 사진 없는 완료 건 | 담당자 재처리 요청 |
| 연계 정합성 | 외부 접수와 내부 수신 건수, 실패·재시도 현황 | 연계 재처리 |
| 개인정보 보유 | 보유기간 경과 자료와 파기 대상 | 파기 승인 절차 |

이 화면은 사전에 정의한 조회 조건과 집계만 제공한다. 원본 데이터 열람은 업무상 필요한 항목으로 제한하고, 조회·엑셀 내려받기·승인 행위는 감사 로그에 기록한다.

## 운영 데이터베이스 권한 원칙

- 애플리케이션 계정은 업무 수행에 필요한 최소 권한만 가진다.
- 최종 담당자 화면은 읽기 전용 복제본 또는 읽기 전용 DB 계정만 사용한다.
- 데이터 수정은 업무 화면의 승인된 기능을 통해서만 수행한다.
- DB 관리 도구 접근은 시스템 관리자에게 별도 부여하며, 최종 담당자 역할과 분리한다.

## 결제 기능

신고 접수 뒤 시민은 카드결제, 계좌이체, 현금결제 중 하나를 선택한다. 결제 완료 전에는 수거 배정이 진행되지 않도록 한다.

| 수단 | 시민 처리 | 시스템 처리 | 결제완료 기준 |
|---|---|---|---|
| 카드결제 | 결제대행사 결제창에서 카드 결제 | 결제 승인 결과와 거래번호를 수신 | 결제대행사 승인 성공 |
| 계좌이체 | 실시간 계좌이체 또는 가상계좌 이체 | 거래번호 또는 입금 확인 결과를 수신 | 결제대행사 또는 수납 연계의 입금 확인 |
| 현금결제 | 지정 수납처 또는 현장 수납처에 현금 납부 | 수납 담당자가 영수증 번호·수납일·수납자를 등록 | 담당자 확인과 수납 증빙 등록 |

현금결제는 시민 화면에서 `현금 납부 대기` 상태와 납부 장소·기한을 안내한다. 수납 담당자만 현금수납 완료로 변경할 수 있으며, 수납번호와 증빙 없이 결제완료로 바꿀 수 없다.

카드번호·계좌 비밀번호 등 금융정보는 저장하지 않는다. 시스템에는 결제수단, 결제금액, 거래번호, 승인·입금 시각, 취소·환불 상태만 최소한으로 기록한다. 취소와 환불은 담당자 승인 및 결제대행사 연계 결과를 포함한 별도 이력으로 관리한다.

## 현장 담당자 모바일 업무 기능

현장 담당자는 휴대전화의 제한된 모바일 업무 화면에서 본인에게 배정된 건만 조회한다. 각 작업 건에는 신고 품목·수량·배출 희망일·신고 사진·배출지점 지도·특이사항을 표시한다.

```text
오늘의 작업 목록
  → 작업 건 선택
  → 신고지점과 현재 위치를 지도에서 확인
  → 길찾기 앱으로 이동
  → 현장 확인
  → 수거완료 또는 미수거 사유 선택
  → 현장 사진과 메모 등록
  → 처리 결과 전송
```

| 기능 | 처리 내용 |
|---|---|
| 작업 목록 | 담당자·수거구역·처리일 기준으로 배정된 건만 표시 |
| 위치 확인 | 신고 좌표와 휴대전화의 현재 위치를 지도에 함께 표시하고, 현장 인접 여부를 안내 |
| 길찾기 | 지도 앱에 신고지점 좌표를 전달하며, 앱 내부에서 경로를 별도로 저장하지 않음 |
| 수거 완료 | 처리시각, 현장 사진, 선택 메모를 등록하고 상태를 수거완료로 변경 |
| 미수거 처리 | 표준 사유와 사진을 등록하고, 시민 보완요청 또는 재배정 흐름으로 전송 |
| 현장 변경 요청 | 신고 위치·품목과 실제 현장이 다르면 사진과 메모를 남겨 담당자 검토를 요청 |

현재 위치 권한은 작업 화면에서만 요청한다. 좌표는 신고지점과의 현장 확인에 필요한 경우에만 처리 이력에 기록하며, 백그라운드 위치 수집과 이동경로 저장은 하지 않는다.
