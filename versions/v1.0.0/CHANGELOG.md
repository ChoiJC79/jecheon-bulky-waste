# 변경 기록

## v1.0.0 · 2026-07-30

- 시민용 대형폐기물 신고 화면을 구현했습니다.
- 품목 분류·검색·규격·수량·예상 수수료 선택을 추가했습니다.
- 카드결제, 계좌이체, 현금결제 안내와 현장 추가요금 안내를 추가했습니다.
- 주소 기반 지도 확인과 현재 위치 좌표 저장 흐름을 추가했습니다.
- 내부 접수·배정, 현장 처리, 읽기 전용 데이터 검증 화면을 추가했습니다.
- SQLite 기반 로컬 개발 API와 감사 로그 저장 구조를 추가했습니다.

## 버전 관리 원칙

- 기능 또는 화면이 달라지는 변경은 `v1.1.0`, `v1.2.0`처럼 마이너 버전을 올립니다.
- 버그 수정과 문구 수정은 `v1.0.1`처럼 패치 버전을 올립니다.
- 새 버전을 만들기 전 직전 버전의 소스와 변경 기록을 `versions/vX.Y.Z/`에 보존합니다.
- 운영 배포본은 별도 승인 후 `v2.0.0`부터 구분합니다.
