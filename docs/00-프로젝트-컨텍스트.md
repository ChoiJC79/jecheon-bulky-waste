# 제천시 대형폐기물 위치기반 양방향 관리 시스템

## 목적

시민의 대형폐기물 배출 신고부터 담당자의 검토, 수거업체의 현장 처리, 최종 담당자의 데이터 검증까지를 하나의 업무 이력으로 관리한다.

## 확정 가정

- 시민 서비스는 인터넷 구간에서 모바일 우선 웹으로 제공한다.
- 담당자 서비스는 새올행정망 등 내부 행정망에서만 접근하는 별도 업무 화면으로 제공한다.
- 외부 시민 서비스와 내부 업무 시스템은 데이터베이스를 직접 공유하지 않는다.
- 구간 간 자료전송은 보안성 검토를 거친 연계 API 또는 중계 구간을 통한다.
- 최종 담당자의 데이터베이스 확인 기능은 읽기 전용 업무 화면으로 제공한다. 운영 데이터베이스에 대한 임의 SQL 실행 또는 쓰기 권한은 제공하지 않는다.

## 사용자와 권한

| 역할 | 접근 구간 | 주요 권한 |
|---|---|---|
| 시민 | 인터넷 | 신고, 결제, 본인 신고 조회, 보완자료 제출 |
| 접수 담당자 | 내부 행정망 | 접수 검토, 보완 요청, 반려, 수거구역 배정 |
| 수거 담당자 또는 수거업체 | 제한된 모바일 업무 화면 | 배정 건 조회, 신고지점·현재 위치 확인, 길찾기, 수거·미수거 처리, 현장 사진 등록 |
| 최종 담당자 | 내부 행정망 | 데이터 정합성 확인, 연계 오류 확인, 통계 확정, 승인 |
| 시스템 관리자 | 내부 행정망 | 품목·수수료·권한·수거구역 설정 |

## 처리 상태

임시저장 → 접수완료 → 계좌이체 입금대기 → 입금확인(결제완료) → 검토중 → 보완요청 또는 반려 또는 배정완료 → 수거예정 → 수거완료 또는 미수거 → 종료

## 설계 원칙

- 위치정보는 배출지점 확인과 수거업무에 필요한 범위에서만 수집한다.
- 수거자의 상시 위치추적은 사용하지 않으며, 작업 건 조회·길찾기·처리 시점에만 현재 위치를 활용한다.
- 상태 변경, 사진 등록, 배정·반려·승인은 모두 처리 이력으로 남긴다.
- 개인정보와 현장 사진은 역할별 최소 권한과 보유기간을 적용한다.
- 카드번호나 계좌 비밀번호는 시스템에 저장하지 않는다.
