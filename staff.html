🚜 현장 수거 태블릿

전화로 받은 신고를
사무실에서 접수해요.

시민 웹 폼으로 보내지 않고, 전화 내용을 입력한 뒤 자동이체 입금을 확인하고 1호차·2호차·예비 안드로이드 태블릿으로 바로 보냅니다. 가까운 미배정 건은 접수·배정 탭에서 묶어 배정할 수 있어요.

사무실 PC 전용 전화 접수

시민에게 공개 웹 신고 화면을 안내하지 않습니다. 품목·위치·사진·수수료를 여기서 입력하고, 자동이체 입금을 확인한 다음 1호차·2호차·예비 태블릿으로 보냅니다. 새올과 연결하지 않으며 외부망만 사용합니다.

현장 태블릿 열기

현장 안드로이드 태블릿 3대

1호차 · 2호차 · 예비. 전송하면 해당 기기만 바로 받습니다. 전체 배정(__ALL__)은 쓰지 않습니다. 위치는 작업 건을 열 때만 쓰고, 상시 추적하지 않습니다.

태블릿 연결 대기

  1. 1접수 입력
  2. 2자동이체 확인
  3. 3담당자에게 전송

전화로 받은 대형폐기물 신고

통화 중 들은 신고자, 품목, 배출 위치, 사진을 입력합니다. 수수료는 시범 품목표로 계산되며 결제수단은 자동이체입니다.

자주 듣는 품목

    예상 수수료 0원

    시범 주소로 빠르게 입력

    지도를 누르면 배출 좌표가 저장됩니다. 좌표가 없어도 접수는 가능합니다.

    결제수단: 자동이체 (계좌이체)

    시범 화면에서는 실제 은행·PG 연계가 없습니다. 입금 여부는 다음 단계에서 담당자가 확인합니다. 계좌 비밀번호나 카드번호는 받지 않습니다.

    자동이체 입금 확인

    시범용 확인입니다. 은행 전산이나 결제대행사를 조회하지 않으며, 입금 금액만 대조한 뒤 확인 처리하세요.

    시범 입금 안내

    제천시 대형폐기물 시범 계좌는 화면에 실계좌를 두지 않습니다. 담당자가 통장·이체내역을 보고 금액이 맞으면 아래 버튼으로 확인하세요. 카드번호·계좌 비밀번호는 입력·저장하지 않습니다.

    입금 대기 목록

    담당자 태블릿으로 전송

    입금이 확인된 건만 1호차·2호차·예비 태블릿으로 보냅니다. 보낸 기기는 새로고침 없이 목록이 바로 갱신됩니다.
